Identity

Custom Art

Two ways to give this SiegeKnight art. Overlay art (keep frame) — recommended for consistency — keeps the shared card frame, shield and description box and drops your character illustration only behind them, so every card's frame and caption box stay identical (the art shows through the window and dimmed behind the description box). Full card art replaces the whole template with a complete, hand-drawn card (the way Squire Bob is set up). For either, paste a hosted path into Art URL or path (e.g. /img/knights/aldera-full-card.png) or use Upload Image. The preview below shows exactly how it renders in-game. Any aspect works — drag the art and use the Scale slider to crop & frame it into the 5:7 card. Then Publish Live Changes from the header. Choose Default icon to revert.
